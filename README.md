# Student Grade Management System

A simple Student Grade Management System built using HTML, CSS, Bootstrap, and JavaScript.

## Project Overview

This project allows users to enter student details and subject marks. The system automatically calculates the total marks, average marks, and grade.

Student records are displayed dynamically in a table and can be filtered, deleted, exported, and stored in browser Local Storage.

## Features

- Add student details
- Enter marks for multiple subjects
- Validate student name and marks
- Calculate total marks
- Calculate average marks
- Calculate grade
- Display student records dynamically
- Delete students
- Filter students by grade
- Filter students by minimum average marks
- Clear filters
- Display class summary statistics
- Prevent duplicate student names
- Store data using Local Storage
- Export student records as CSV
- Download student report

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Local Storage

## Subjects

The system contains four subjects:

- Math
- Science
- English
- History

Each subject has a maximum mark of 100.

## Grade Calculation

| Average Marks | Grade |
|---------------|-------|
| 90 - 100      | A     |
| 80 - 89       | B     |
| 70 - 79       | C     |
| 60 - 69       | D     |
| Below 60      | Fail  |

The Student Grade Management System is a beginner-friendly JavaScript project that demonstrates how HTML, CSS, Bootstrap, and JavaScript can be combined to create a functional web application.
